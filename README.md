### What I'm Breaking & Building

<samp>

#### [neural-particle-sandbox](https://github.com/CalmOutlaws7)
> **Computer Vision meets WebGL**
* Tracks real-time hand gestures via webcam, piping raw matrix transforms into a 3D WebGL pipeline.
* Controls a swarm of 8,000+ interactive dynamic particles and physical 3D objects locked at 60 FPS.
* **Stack:** `Three.js` `React Three Fiber` `MediaPipe` `Next.js` `GLSL`

#### [collaborative-whiteboard](https://github.com/CalmOutlaws7)
> **Real-time Distributed Vector Canvas**
* Handles multi-user concurrent mutations with zero UI stutter.
* Implemented custom message ordering over WebSockets backed by Redis to eliminate state race conditions.
* **Stack:** `Next.js` `Socket.io` `Redis` `TypeScript` `Tailwind`

#### [student-buddy-extension](https://github.com/CalmOutlaws7)
> **Production-Grade Productivity Engine**
* Browser automation tool engineered with a strict event-driven chrome architecture.
* Features isolated background service workers, cross-script messaging, and decoupled state management.
* **Stack:** `Chrome Extension API` `TypeScript` `Web Storage` `Tailwind`

#### high-performance-dash `[Private Repo]`
> **Enterprise-Grade Telemetry Visualization**
* Designed for ultra-low latency data hydration under heavy visual data loads.
