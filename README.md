### What I'm Breaking & Building

#### [neural-particle-sandbox](https://github.com/CalmOutlaws/neural-particle-sandbox)
**Computer Vision meets WebGL**
* Tracks real-time hand gestures and maps them into a GPU-powered particle simulation.
* Pushing WebGL rendering and animation loops to keep everything running smoothly.
* **Stack:** `Three.js` · `React Three Fiber` · `MediaPipe` · `GLSL`

#### [collaborative-whiteboard](https://github.com/CalmOutlaws/collaborative-whiteboard)
**Real-time Collaborative Canvas**
* Built around WebSockets and Redis for multi-user collaboration.
* Exploring synchronization, concurrent edits, and low-latency interactions.
* **Stack:** `Next.js` · `Socket.io` · `Redis` · `TypeScript`

#### [smart-notification-hub](https://github.com/CalmOutlaws/smart-notification-hub)
**Notification Routing Engine**
* Routes and categorizes notifications with real-time updates.
* Experimenting with Supabase Realtime and PostgreSQL RLS.
* **Stack:** `Next.js` · `Supabase` · `PostgreSQL` · `Tailwind`

#### [pillar](https://github.com/CalmOutlaws/pillar)
**Personal Life Operating System**
* Android app focused on helping users Earn, Save, Grow, and Enjoy.
* Built with modern Android architecture using Jetpack Compose.
* **Stack:** `Kotlin` · `Jetpack Compose`

#### [monk-mode-os](https://github.com/CalmOutlaws/monk-mode-os)
**Executive Command Center**
* Personal dashboard for habits, academics, workouts, and coding goals.(Private)
* Built to reduce friction and stay consistent every day.
* **Stack:** `Next.js` · `React` · `TypeScript`

#### [student-buddy-extension](https://github.com/CalmOutlaws/student-buddy-extension)
**Browser Productivity Toolkit**
* Event-driven Chrome extension with background workers and messaging.
* **Stack:** `Chrome Extension API` · `TypeScript`

#### [leetcode-solutions](https://github.com/CalmOutlaws/leetcode-solutions)
**DSA Journey**
* Daily collection of accepted LeetCode solutions synced automatically.
* Learning one problem at a time and improving consistency.
* **Stack:** `C++` · `LeetHub`
